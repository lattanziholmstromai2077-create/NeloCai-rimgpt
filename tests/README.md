# RimGPT 验证清单

## 每次变更

1. 检查 `git status --short --branch`、`git diff --check` 和 `git diff --cached --check`，复查暂存文件。
2. 用 [暂存构建和回归命令](../docs/ENVIRONMENT.md) 编译、比对并运行隔离测试。记录游戏、依赖、输入及产物 SHA256，明确缺项和验证边界。
3. 实机验证使用独立用户目录和测试存档，确认实际 Mods、Config、Saves 和日志位置，记录正式安装目标、启用配置和原存档哈希。进入主菜单、读取测试档、触发对应场景并核对日志。
4. LLM/API 变更默认使用模拟响应或离线配置。真实请求由用户决定，密钥通过本地安全配置注入。
5. 验证失败时退出测试实例，恢复隔离副本或重新创建它。正式部署后的回退以专项清单为准，退出游戏后校验当前目标与备份哈希，再恢复原件。保留原始存档。
6. 通过验证的可复现维护基线可以打 Git 标签。游戏部署或发行包依实际实机结果另行处理。
