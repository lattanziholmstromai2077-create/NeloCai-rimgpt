# RimGPT 验证清单

## 每次变更

1. 运行 `git status --short --branch`、`git diff --check` 和 `git diff --cached --check`。检查暂存文件、配置占位符和附件，确保差异只含本次变更。
2. 用 [暂存构建命令](../docs/ENVIRONMENT.md#暂存构建) 编译相关模块。记录游戏、PowerShell、引用版本、命令、输出和 SHA256。缺少源码或引用时，记录实际缺项和阻塞的检查。
3. 实机验证前创建独立游戏实例和测试存档副本。核对实例的 Mods、Config 和 Saves 路径；对正式目标文件、启用配置和正式存档留存 SHA256。
4. 启动隔离实例到主菜单，再读取副本，复现目标场景。核对预期行为、已知兼容项及相邻流程，必要时重启后重载。比较启动、读档、运行和退出日志，只在记录中保留脱敏片段。
5. 如果需要验证 LLM/API 集成，默认使用模拟响应或离线测试配置。真实请求由用户决定，密钥通过仅在本机保存的安全配置注入。
6. 测试失败时退出测试实例，按专项记录恢复隔离目录备份或重新生成测试副本。经授权部署到正式目录后如需回退，先退出游戏，按备份记录逐文件恢复到核对过的路径并比对哈希。保留原始存档。
7. 记录执行结果与未覆盖场景。首个包含入库源码且完成相应实机验证的基线才适合发布版本标签。
