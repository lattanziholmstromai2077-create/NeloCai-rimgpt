- 本轮独立跑通诊断标记、Ratkin 与 DMS 缓存、Facial Animation 克隆钩子和手术列表只读回归。实机记录来自历史隔离测试，范围见 [验证结果](../tests/README.md)。

- 接手时先核对真实游戏引用和现装 DLL 哈希，再按 [构建和验证](ENVIRONMENT.md) 重跑。常规任务遵循 [维护流程](MAINTENANCE.md)。
